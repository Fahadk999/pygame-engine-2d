# Pygame Mini 2D Game Engine
This is project where making games using pygame will be really easy.
The goal is to provide resuable components for your game development.
You just have to include this repo in your game folder and import classes.

### Features to be Implemented
- Making Componets easily.
- Adding complex physics.
- Making Sprites animate.
- Collision handling and detection.
